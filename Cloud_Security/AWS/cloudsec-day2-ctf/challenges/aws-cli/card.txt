🎯 DAY 2 TOPIC
AWS CLI in WSL — your terminal gateway to the cloud.

🔎 THE IDEA
The AWS Console is for humans. The CLI is for automation, scripts, and speed.
Cloud security engineers live in the terminal.

☁️ CLOUD SECURITY BRIDGE
Every AWS action is an API call.
CLI = direct API access = scriptable = auditable = automatable.

🎮 TASKS
1. In WSL: `aws configure`
   - AWS Access Key ID: (from IAM admin user)
   - AWS Secret Access Key: (from IAM admin user)
   - Default region: ap-south-1
   - Default output: json
2. Verify: `aws sts get-caller-identity`
   Should show your admin user ARN.
3. When done, open flag.txt for this mission.
