# AWS Labs

Small hands-on exercises linked to the theory notes. Each lab explains what it tests, how to set it up and how to clean up afterwards.

## Learning order

1. [Day 1: IAM least privilege](day-01-iam-least-privilege.md) — create a small test policy and check its permissions in the IAM Policy Simulator.

## Before starting

- Use an AWS account you control or have permission to use.
- Check the permissions and resources a lab needs before running it.
- Never commit access keys, passwords, account IDs or other private information.
- Check the cleanup steps before creating resources.
- Stop if the console shows an unexpected resource or cost.
