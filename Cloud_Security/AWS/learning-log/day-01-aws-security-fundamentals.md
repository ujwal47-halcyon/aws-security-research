### Key Notes
- **IAM:** Grant only the permissions required for a user's role.
- **Excessive permissions:** Unnecessary write permissions can allow unauthorized changes.
- **EC2 patching:** The customer is generally responsible for patching the guest operating system.
- **Amazon Inspector:** Identifies supported vulnerabilities and security findings.
- **Patch Manager:** Helps manage and apply operating system patches.
- **Shared Responsibility:** AWS secures the underlying cloud infrastructure; customers handle their responsibilities within the cloud.
